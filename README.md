# LES HÉRITIERS

**Pourquoi notre monde est-il ainsi ?**

Atlas mondial interactif des sources de l'histoire humaine. Projet documentaire mobile first.

## Principe

LES HÉRITIERS ne prétend pas détenir le savoir historique : il facilite la découverte, la consultation et la comparaison de sources primaires et de travaux scientifiques, avec leur provenance, leurs limites et leurs droits.

## Démarrage

```bash
npm install
npm run dev
```

Ouvrir http://localhost:3000.

## Première version

Interface mobile de consultation des sources. Les entrées de démonstration sont explicitement fictives et ne doivent pas être publiées comme faits historiques.
